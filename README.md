# GWSTKit

Reusable Flutter/Dart packages extracted from apps I build in public
([JipCook](https://jipcook.pages.dev) and others).

| Package | What it does |
|---------|--------------|
| [`subject_sticker`](packages/subject_sticker) | On-device subject cutout (ML Kit) + sticker-style border rendering — white margin, colored contour line, stitch dashes, rounded finishing. |

Everything here is battle-tested in a real app first, then extracted.
APIs may still change while the source apps evolve (pre-1.0).
